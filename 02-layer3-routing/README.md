# Layer 3 Routing

Hands-on Cisco routing labs covering static routing, backup paths, OSPFv2, IPv6 routing, and OSPFv3. This section focuses on building routed networks, understanding how routers select paths, validating routing-table behavior, and testing convergence and recovery after network failures.

---

## Focus Areas

* Static and default routing
* Floating static routes and backup paths
* Administrative distance
* Longest-prefix match
* Routing-table interpretation
* Primary-path failure and recovery
* Single-area OSPFv2
* OSPF neighbor formation and adjacency states
* Router ID selection
* Broadcast and point-to-point OSPF network types
* DR and BDR election
* OSPF cost and path selection
* Default-route advertisement
* OSPF convergence
* IPv6 global unicast and link-local addressing
* IPv6 Neighbor Discovery
* IPv6 static and default routing
* Dual-stack IPv4 and IPv6 operation
* OSPFv3 routing and convergence

---

## Labs

| Lab | Description |
| :--- | :--- |
| **01 — Static, Default & Floating Routing** | Configure static, default, and floating static routes while testing administrative distance, longest-prefix match, primary paths, backup paths, and failure recovery. |
| **02 — Single-Area OSPFv2** | Build a dynamic IPv4 routing network, form OSPF adjacencies, control route selection, examine DR and BDR behavior, and verify convergence after link failures. |
| **03 — IPv6 Static Routing & OSPFv3** | Configure IPv6 addressing, static and default routes, dual-stack connectivity, and dynamic IPv6 route exchange using OSPFv3. |

---

## Lab Structure

Each lab includes:

* Project overview
* Network topology
* Addressing and routing design
* Device configurations
* Routing-table verification
* Neighbor and protocol verification
* End-to-end connectivity testing
* Path-failure and recovery testing
* Key takeaways
