# Layer 3 Routing

Hands-on Cisco routing labs covering static routing, OSPFv2, IPv6 routing, and OSPFv3. This section focuses on how routers learn routes, select forwarding paths, exchange routing information, and recover after network failures.

---

## Focus Areas

* Static, default, and floating static routes
* Administrative distance, longest-prefix match, and path selection
* Routing-table interpretation and backup-path activation
* Single-area OSPFv2 adjacencies and route exchange
* Router IDs, network types, DR/BDR elections, and OSPF cost
* OSPF convergence and default-route advertisement
* IPv6 addressing, Neighbor Discovery, and static routing
* Dual-stack operation and OSPFv3 routing
* Link-failure testing and network recovery

---

## Labs

| Lab | Description |
| :--- | :--- |
| **01 — Static, Default & Floating Routing** | Configure manual, default, and backup routes while testing routing-table decisions, path selection, and failover. |
| **02 — Single-Area OSPFv2** | Build a dynamic IPv4 routing network, verify OSPF adjacencies and path selection, and test convergence after link failures. |
| **03 — IPv6 Static Routing & OSPFv3** | Configure IPv6 addressing, static and default routing, dual-stack connectivity, and dynamic IPv6 routing with OSPFv3. |

---

## Lab Structure

Each lab includes a project overview, network topology, addressing design, device configurations, routing verification, connectivity testing, failure testing, and key takeaways.
