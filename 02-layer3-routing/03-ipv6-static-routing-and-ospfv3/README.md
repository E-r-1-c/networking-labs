# IPv6 Static Routing & OSPFv3

This folder is reserved for the final Layer 3 routing lab. The completed lab will extend the IPv4 routing work into IPv6 addressing, static routing, default routing, and dynamic route exchange with OSPFv3.

---

## Planned Focus Areas

* IPv6 global unicast and link-local addressing
* IPv6 static and default routes
* Dual-stack IPv4 and IPv6 operation
* OSPFv3 router IDs and neighbor relationships
* Dynamic IPv6 route exchange
* Passive interfaces
* Path selection and routing-table verification
* Link-failure testing and OSPFv3 convergence
* End-to-end IPv6 connectivity

---

## Planned Lab Structure

The completed lab will include a project overview, network topology, IPv6 addressing design, device configurations, routing verification, connectivity testing, failure testing, recovery testing, screenshots, and key takeaways.

---

## Environment

* Cisco Packet Tracer
* Cisco IOS
* IPv6
* OSPFv3
