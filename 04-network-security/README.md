# Network Security

Hands-on Cisco network security labs covering traffic filtering, access-layer protection, and secure device management.

This section focuses on controlling network traffic, protecting switched networks from common local attacks, and securing administrative access to network devices.

---

## Focus Areas

- Access control lists
- Port Security
- DHCP Snooping
- Dynamic ARP Inspection
- IP Source Guard
- SSH and VTY security
- Local authentication
- Security verification and attack testing

---

## Labs

| Lab | Description |
| :--- | :--- |
| **01 — ACL Traffic Filtering** | Configure standard and extended ACLs to control traffic between networks and verify permitted and denied traffic. |
| **02 — Access-Layer Security Hardening** | Combine Port Security, DHCP Snooping, Dynamic ARP Inspection, and IP Source Guard to protect access ports from unauthorized devices, rogue DHCP, ARP spoofing, and source-address spoofing. |
| **03 — SSH & VTY Hardening** | Configure SSH, local authentication, and VTY restrictions to secure remote device management. |

---

## Lab Structure

Each lab includes a topology, security requirements, configuration, verification, attack or failure testing where appropriate, and key takeaways.

---

## Environment
