# Spanning Tree Protocol (STP & RSTP)

## Overview

This lab demonstrates how Spanning Tree Protocol (STP) prevents Layer 2 switching loops in a redundant switched network.

A three-switch topology with redundant links was created to observe root bridge election, spanning-tree port roles, and forwarding states. Rapid PVST+ was configured, bridge priorities were adjusted to control root bridge placement, and BPDU Guard was enabled on access ports to improve Layer 2 security.

---

## Objectives

- Build a redundant Layer 2 topology
- Configure Rapid PVST+
- Control root bridge election
- Identify root, designated, and alternate ports
- Verify forwarding and blocking states
- Configure PortFast and BPDU Guard
- Validate STP loop prevention

# Configuration

The following tasks were completed during this lab:

- Built a redundant three-switch Layer 2 topology
- Enabled Rapid PVST+ on all switches
- Configured SW0 as the primary root bridge for VLANs 10 and 20
- Configured SW1 as the secondary root bridge for VLANs 10 and 20
- Enabled PortFast on access ports connected to end devices
- Enabled BPDU Guard to protect access ports from unauthorized switches

The topology was designed with redundant paths so STP could determine the best forwarding paths while preventing Layer 2 loops.

The spanning-tree output was reviewed to verify the elected root bridge, bridge priority, root path information, and switch roles.

Command used:

```cisco

```

![Root Bridge Verification](./images/01-primary-root-verification.png)

Verified:

- SW0 became the root bridge.
- Root bridge priority was successfully adjusted.
- The spanning-tree topology was built around the selected root bridge.

The spanning-tree output was reviewed to identify root ports, designated ports, and alternate ports.

Command used:

![Port Role Verification](./images/02-blocking-port-verification.png)

Verified:

- Root ports were selected on non-root switches.
- Designated ports remained in the forwarding state.
- A redundant path transitioned into an alternate/discarding state.
- STP prevented a Layer 2 switching loop while maintaining redundancy.

## BPDU Guard Verification

BPDU Guard was tested on SW2 by introducing BPDU traffic on a protected PortFast-enabled access port.

The switch detected the unexpected BPDU and automatically placed the interface into an err-disabled state. This prevents an unauthorized switch from participating in the spanning-tree topology.

Verification:

```text
Syslog message generated by the switch after the BPDU Guard violation
```

![BPDU Guard Syslog Verification](./images/03-bpduguard-syslog.png)

Verified:

- BPDU Guard detected the unexpected BPDU.
- The affected access port was automatically disabled.
- The spanning-tree topology was protected from an unauthorized Layer 2 device.

# STP Port Roles

| Port Role | Purpose |
|-----------|---------|
| Root Port | Best path from a non-root switch toward the root bridge |
| Designated Port | Forwarding port responsible for a Layer 2 segment |
| Alternate Port | Backup path placed into a discarding state to prevent loops |

---

# Results

The completed topology successfully demonstrated STP loop prevention and Layer 2 redundancy.

Results:

- SW0 operated as the primary root bridge.
- SW1 provided secondary root bridge functionality.
- SW2 operated as an access switch with edge protection enabled.
- STP successfully blocked redundant paths without removing physical redundancy.
- Port roles and forwarding states were verified.
- BPDU Guard successfully protected access ports from unexpected BPDU traffic.

---

# Key Takeaways

- STP prevents Layer 2 loops by controlling which switch ports are allowed to forward traffic.
- Root bridge election is determined by the lowest Bridge ID.
- Bridge priority can be modified to control root bridge placement.
- Root ports provide the best path toward the root bridge.
- Designated ports forward traffic for each Layer 2 segment.
- Alternate ports maintain redundancy while preventing loops.
- Rapid PVST+ provides faster convergence through per-VLAN spanning-tree operation.
- PortFast improves access device connectivity.
- BPDU Guard protects edge ports from unauthorized switches.
